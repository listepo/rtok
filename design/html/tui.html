Terminal UI

rtok tui (src/tui, ratatui) renders the same thirteen pages as the web admin, from the same model::pages() list. The first tab is titled usage (the web route is overview). Terminal colours are fixed to the dark brand palette in both themes, as a terminal would draw them. Sample data.
